Turning Unstructured Prospect Data Into Rigorous Opportunity Briefs

How Context & Muse designed and deployed the Client Opportunity Engine—a specialized decision support system that parses prospect websites, filters bad-fit leads via negative checklists, and generates tangible prototype specifications.

Domain Commercial Operations / Decision Support
Live Product leadintelligencehub-psi.vercel.app ↗
Primary Outputs Opportunity Brief (.md), Prototype Spec, Outreach Kit
Architecture React / TypeScript / Tailwind / Vite
Fig 3.0: Live interface of Client Opportunity Engine with Opportunity Brief, Prototype Spec, and Outreach Kit tabs. Seller Profile Calibration • Negative Check Triggers
01 / The Core Friction

The Cost of Unstructured Sales Research

Agency and studio business development is plagued by wasted effort: hours spent researching companies that lack budget, chasing misaligned technical requirements, or sending generic boilerplate messages that get ignored.

Conversely, creating bespoke concepts for every lead is too slow to maintain momentum.

"How do we systematically qualify commercial opportunities, identify verified technical gaps, and generate tailored prototype specifications in minutes?"

02 / Workflow & Calibration

Seller Profile Calibration & Negative Checks

The engine begins with Seller Profile Calibration. Rather than using generic qualification criteria, the operator configures their studio's target project scope, pricing floors, core capabilities, and non-negotiable negative check filters without exposing internal defaults publicly.

Step 1
Ingestion & Signal
Extracts prospect industry, business model, estimated scale, and current technical architecture.
Step 2
Watchlist & Disqualification
Evaluates strict negative checks (e.g. outdated stack, uncalibrated budget, scope mismatch) before proceeding.
Step 3
Artifact Synthesis
Generates complete Opportunity Brief, Prototype Specification, and 60-second Loom script.
03 / System Outputs

Structured Artifacts Generated

For qualified prospects, the engine outputs four synchronized deliverables:

📄 Opportunity Brief (.md)
Executive diagnostic summary, tech stack teardown, commercial friction points, and recommended engagement tier.
🛠️ Prototype Specification
Concrete concept spec including user flows, data schema, recommended stack, and measurable business outcomes.
✉️ 1-to-1 Outreach Kit
Ultra-personalized email draft referencing specific technical gaps rather than generic sales fluff.
🎬 60-Second Video Script
High-impact walkthrough script designed for async Loom teardowns showing immediate value.
04 / Frontend Architecture

Modular React & State Architecture

Built as a reactive, single-page application deployed on Vercel:

  • State Management: Centralized profile and prospect state supporting seamless Markdown and JSON export.
  • Zero-Latency Filtering: Instant evaluation of watchlist triggers and disqualification rules.
  • Multi-Tab Workspace: Tabbed views for Company Analysis, Buyer Personas, Prototype Concepts, Outreach Kit, and Full Markdown Export.
