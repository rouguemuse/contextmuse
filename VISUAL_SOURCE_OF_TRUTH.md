# Visual Source of Truth Ledger

> **Policy Directive**: Every public visual representing a project must be traceable to an actual verified source. No synthetic dashboards, AI hallucinations, or cross-project contamination are permitted to represent real client deliverables or software systems. If an asset cannot be verified, it is purged and replaced with clean semantic typography or neutral system specifications.

---

## 1. Summary of Visual Audit Categories

| Classification | Meaning | Policy Action |
|:---|:---|:---|
| **VERIFIED AUTHENTIC** | Actual production screenshot or artifact directly from the real system. | Retain as primary evidence. |
| **VERIFIED SANITIZED DEMO** | Real working software loaded with dummy / test / scrubbed data. | Retain with explicit anonymization disclosure. |
| **UNVERIFIED CONCEPT** | Synthetic, conceptual, or design mockup. | Clarify framing as concept art or replace with specs. |
| **WRONG PROJECT / CONTAMINATION** | Image belonging to another project or domain. | Immediately remove image. |
| **PRIVACY / CONFIDENTIAL RISK** | Real client data that shouldn't be public without redaction. | Anonymize or redact. |
| **SYNTHETIC / FABRICATED** | AI-generated or invented interface presented as a real product. | Immediately purge from public code. |
