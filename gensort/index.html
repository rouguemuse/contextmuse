IV // SYSTEM FAQ

Frequently Answered Queries

Does GenSort upload my files?

No. GenSort runs entirely in your browser using local file handles. Your images, documents, and data files are never sent to a server. Processing and classification take place completely on your machine.

What export formats are supported?

You can export sorted indices, structure logs, custom tags, or organized references as CSV metadata manifests, which can be re-imported or referenced by other workflow scripts.

How does the pay-on-export work?

You can run sorting sessions, apply tags, filter directories, and view libraries as much as you like without restriction. When you are ready to export the final structured manifest, the app will prompt you for an export license code.
