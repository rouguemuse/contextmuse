System & Content Architecture

This project focuses on normalizing scattered, inconsistent public service listings into a clean database. When designing public-interest guides, the content architecture must account for the changing nature of resources, providing users with clear validation indicators:

Taxonomy Design

Defining service classifications (Housing, Food, Transportation) so users filter resources based on their immediate crisis level.

Plain Language Translation

Converting dense administrative eligibility criteria into readable lists of required documents and cost points.

Source Traceability

Providing clear metadata (Verification status, review dates) so operators trust the currency of the directory data.

Boundary Notice: Resource details can change. The directory organizes and summarizes information but does not replace confirmation with the listed provider or qualified professionals.
